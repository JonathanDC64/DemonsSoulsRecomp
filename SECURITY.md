# Security

## Reporting a problem

If you find a security problem in this project, please report it privately, not in a public issue.

Use GitHub's private reporting: on this repository's **Security** tab, choose **Report a vulnerability**. Only the
maintainer sees the report.

Please include:

- the version (the release name, or the commit if you built it yourself) and your system (Windows or Linux);
- which part it's in: the game program, setup, updates, or online play;
- what happens, and the steps to make it happen;
- what someone could do with it;
- whether anyone else knows about it.

Please keep the details private until a fix is out.

Problems in the runtime, [ps3recomp](https://github.com/JonathanDC64/ps3recomp), can be reported here too. So can
problems in the game's own code that other players can reach: the port can add checks around it.

## What happens next

You should get a reply within a week. A fix goes into the next release, and its notes credit you if you'd like.

Only the newest release gets fixes.

## Online play

Online play runs on the project's own server. Report problems with it here too.

Please don't test on other players, and don't slow the server down or fill it with data. If you need to test
something online, say so in your report and we'll find a way.

Other servers are run by other people: report problems with them to their owners.
