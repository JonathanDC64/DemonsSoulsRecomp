# The player's download (tools/release/package.py): the files of the source tree that the program and setup use. They
# go in setup/ beside the program, in the same layout, so setup finds them as it does in a source tree. The whole tree
# stays in the source zip.
#
# A line is a path from the root of the tree, ps3recomp/ being the fork at its pin. * is any name in one folder, ** any
# path below one. A line that matches nothing fails the packaging, as does a file game_build*.json names that no line
# takes, or a script here that imports one of the tree's scripts that no line takes. release-check.yml runs the lift's
# tools from the packaged tree too.
